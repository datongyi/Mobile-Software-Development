## 🚀 仓库运行指南

### 1. 获取代码

将本仓库克隆到本地环境：

```bash
git clone [https://github.com/datongyi/Mobile-Software-Development.git](https://github.com/datongyi/Mobile-Software-Development.git)
cd Mobile-Software-Development
```

### 2. 运行实验 1

1. 打开**微信开发者工具**。
2. 选择导入项目，**使用微信开发者工具直接导入 `实验1：第一个微信小程序` 这个子目录**。
3. 在基本信息中**选择自己的 AppID**（或在 `project.private.config.json` 中配置），完成后点击“编译”即可预览效果。

**功能体验指南**：

- **动态专属问候**：在页面中部的输入框（`<input>`）内输入你的名字，顶部的问候语会实时变为 `hello [输入的名字]!`；如果清空输入框，文字会自动恢复为默认的 `world`。
- **按钮状态切换**：点击绿色的“点击切换”按钮，页面顶部的文本将在 `boy` 和 `world` 之间动态来回切换。
- **图片条件渲染**：点击蓝色的“显示/隐藏图片”按钮，可以控制页面中央图片的展示与消失，体验 `wx:if` 指令的渲染效果。
