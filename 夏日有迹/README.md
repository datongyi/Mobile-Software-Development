# 夏日有迹

一款原生微信小程序手账：记录日常、回看时间线、制作分享卡，并在自行配置本地代理后使用 AI 笔友。

![夏日有迹首页预览](./docs/home-preview.jpg)

## 项目简介

项目以本地账户组织记录。用户可以写文字、添加照片与标签、保存草稿，之后通过搜索、时光视图和展览馆回看。核心记录功能无需云环境或 API 密钥；AI 内容是可选能力，需由使用者自行配置服务商和本机代理。

## 项目目标与功能

| 方向 | 已实现内容 |
| --- | --- |
| 记录与整理 | 一日三刻、照片、草稿、搜索、心情和标签筛选、收藏、版本与回收站 |
| 时间与探索 | 日历热力图、往年今日、时光胶囊、记忆共鸣、情绪色谱、关系网、50 种三级夏日奇物 |
| 分享与备份 | 手账、拍立得和笔友回信三种分享卡；包含照片的账户备份与导入 |
| AI 笔友 | 回信、阶段回顾、平行时空、明日一问、双声道五种模式；建议需主动采纳 |

完整交互说明见 [功能指南](./docs/feature-guide.md)。本地账户只用于设备内数据隔离，不等同于身份认证；时光胶囊的时间锁也不提供加密保护。

## 开发环境

| 项目 | 要求 |
| --- | --- |
| 客户端 | 微信开发者工具，原生 WXML、WXSS、JavaScript |
| 小程序基础库 | `project.config.json` 配置为 3.17.3 |
| 本地检查和 AI 代理 | Node.js 22 或更新版本 |
| AI 服务 | 可选；DeepSeek、OpenAI 或兼容 Chat Completions 的服务 |

本轮已通过源码检查和 35 项 Node.js 测试；未进行真机或真实 AI 服务调用验收。

## 项目结构

```text
夏日有迹/
├── miniprogram/       # 页面、状态模块和本地资源
├── server/            # 可选 AI 本地代理与配置示例
├── scripts/           # 源码检查与素材生成
├── tests/             # Node.js 逻辑和代理测试
├── docs/              # 功能、配置与素材说明
├── project.config.json
└── package.json
```

`miniprogram/lib/store.js` 管理账户和记录状态，`backup.js` 处理导入导出，`curios.js` 计算奇物进度，`showcase.js` 生成展览馆数据。`server/index.js` 在本机代理 AI 请求，密钥不放入小程序端。

## 运行方法

1. 克隆仓库，在微信开发者工具中导入 `夏日有迹` 目录（其中有 `project.config.json`）。
2. 使用自己的小程序 AppID 或适用的测试配置，编译后即可使用本地手账功能。
3. 如需 AI 笔友，按 [AI 本地配置](./docs/ai-setup.md) 创建 `server/.env`、启动代理，并在开发者工具中配置本地调试。不要提交密钥；此代理默认只供电脑模拟器使用。

```bash
git clone https://github.com/datongyi/Mobile-Software-Development.git
cd Mobile-Software-Development/夏日有迹
npm run check
npm test
```

测试使用 Node.js 内置测试运行器；运行现有应用不需要安装 npm 依赖。只有重新生成图标素材时才需要先运行 `npm ci`，再执行 `npm run assets`。

## 核心实现与验证

记录按本地账户隔离。搜索、关联推荐、展览馆和 AI 输入只读取当前账户可见记录；已删除或未解锁内容不参与派生结果。备份包含照片数据，导入时创建新账户，不覆盖现有账户。AI 返回与发起请求的账户、记录版本绑定；迟到结果不会写入切换后的账户或已修改记录。

| 检查 | 本轮结果 |
| --- | --- |
| `npm run check` | 10 条路由、40 个页面文件及 JSON、JavaScript 语法和静态/动态资源检查通过 |
| `npm test` | 35 项测试通过，覆盖备份、账户隔离、可见性、奇物规则和 AI 代理契约等 |

模拟器界面、真机系统能力以及真实 AI 服务需在相应环境中另行验收。无密钥时核心手账仍可使用，AI 不会伪造真实回信。
