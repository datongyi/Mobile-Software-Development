# 高校新闻网设计说明

## 目标

按 `lab3.pdf` 与 `todo.md` 完成一个包含首页、新闻详情页和个人中心页的微信小程序。首页和个人中心通过 tabBar 切换，新闻详情通过普通页面跳转打开。

## 页面与数据流

- 首页读取 `utils/common.js` 中的本地新闻数据，展示三张自动轮播图片和新闻列表。
- 点击首页或收藏列表中的新闻，携带新闻 `id` 跳转到详情页。
- 详情页按 `id` 获取完整新闻，并通过 `favoriteNews` 本地缓存数组添加或取消收藏。
- 个人中心未登录时只显示登录按钮和空收藏；登录成功后保存微信头像、昵称，并读取收藏列表。

## 关键约束

- 图片全部使用项目 `images` 目录中的本地素材，避免网络资源失效。
- 收藏使用单独的 `favoriteNews` 缓存键，不遍历全部缓存，避免把日志和用户资料误当成新闻。
- 用户通过 `chooseAvatar` 和 `type="nickname"` 选择微信头像、填写微信昵称；资料使用 `campusNewsUser` 缓存键，以便重新进入小程序后保留登录展示状态。
- 详情页图片宽度使用 `700rpx`，遵循 PDF 中的兼容性提示。

## 验证

- Node 测试验证收藏数据的新增、去重、取消和异常缓存清洗。
- Node 语法检查覆盖所有业务 JavaScript 文件。
- 微信开发者工具编译 WXML/WXSS，并打开三个页面检查运行状态。
