# 高校新闻网综合扩展设计

## 目标

在现有首页、新闻详情页和个人中心页的基础上，继续使用本地模拟数据，增加新闻发现、用户互动、收藏管理和界面体验功能。其中本阶段重点实现新闻评论功能。

## 已确认的扩展范围

- 新闻分类筛选
- 新闻关键词搜索
- 新闻点赞与取消点赞
- 新闻评论输入框
- 评论列表展示
- 评论删除
- 阅读历史
- 收藏夹删除和排序
- 首页快捷入口卡片
- 夜间模式
- 详情页分享
- 空状态、加载状态和下拉刷新
- 个人中心数据统计

## 评论功能设计

### 权限规则

- 未登录用户可以查看评论、点赞和取消点赞，但不能发表评论。
- 未登录时详情页隐藏评论输入框，显示“登录后才能发表评论”的入口；点击后切换到个人中心页。
- 登录用户发表评论时，昵称和头像使用个人中心保存的本地用户资料。
- 评论提交方法和评论公共模块都必须校验有效登录资料，不能只依赖 WXML 隐藏输入框。
- 任意评论都可以删除。删除前必须弹出确认框，确认后才执行删除。
- 该删除规则适合课程演示，不模拟服务端权限校验。

### 数据存储

- 每条新闻的评论单独保存到本地缓存，键名格式为 `newsComments_<newsId>`。
- 评论对象字段固定为：
  - `id`：本地生成的唯一标识
  - `nickname`：发表评论时的登录用户昵称；历史游客评论仍按原值兼容展示
  - `avatarUrl`：发表评论时的登录用户头像；历史游客评论可以为空
  - `content`：评论正文
  - `createdAt`：创建时间戳
  - `createdText`：用于展示的时间文本
- 读取缓存时过滤缺少 `id`、`nickname`、`content` 或 `createdAt` 的异常对象。
- 列表按 `createdAt` 从新到旧排序。

### 详情页交互

- 新闻正文、收藏按钮之后显示“评论（数量）”区域。
- 评论列表展示昵称、时间、内容和删除按钮。
- 底部提供多行输入框和“发表评论”按钮。
- 评论内容去除首尾空格；空内容不提交并提示“请输入评论内容”。
- 成功提交后清空输入框，评论数量加一，新评论显示在列表顶部。
- 点击删除后调用确认弹窗；用户确认后从缓存和当前页面列表中同时移除。
- 新闻详情重新打开或从收藏列表进入时，重新读取对应新闻的评论缓存。

## 其他扩展设计

### 首页

- 增加分类栏和关键词搜索框。
- 搜索与分类同时生效，结果为空时显示空状态。
- 新闻进入详情页时写入阅读历史并累加本地阅读量。
- 增加快捷入口卡片，入口跳转到分类、收藏或历史区域。
- 支持下拉刷新，刷新时显示短暂加载状态。

### 个人中心

- 收藏列表支持按收藏时间排序和单条删除。
- 增加收藏数、点赞数、评论数、阅读数统计卡片。
- 夜间模式开关使用本地缓存持久化，首页、详情页和个人中心统一应用。
- 登录态只显示“退出登录”，退出前弹出确认框；需要更换用户时，退出后重新填写头像昵称登录。
- 退出登录只清除 `campusNewsUser` 与 `app.globalData.userInfo`，保留收藏、点赞、阅读历史、评论、阅读量和主题。
- 未登录时个人统计、收藏、历史和点赞列表隐藏，夜间模式开关仍可使用；重新登录后从保留的本地缓存恢复个人数据展示。

### 详情页

- 增加点赞/取消点赞和分享按钮。
- 增加“返回顶部”操作，长文章阅读更方便。

## 错误处理

- 新闻 id 无效时显示“新闻不存在”，不渲染空详情。
- 本地缓存损坏时按空列表处理，不阻断页面打开。
- 评论提交、删除失败时保留当前输入和页面列表，并显示错误提示。
- 所有交互状态均在操作成功后更新，避免按钮状态与缓存不一致。

## 验证标准

- 未登录时点赞和取消点赞可用，评论输入框不可用。
- 点击评论登录提示可以切换到个人中心页。
- 登录后评论使用当前用户昵称和头像。
- 退出登录后业务缓存不丢失，重新登录后可恢复展示。
- 同一新闻的评论不会出现在另一条新闻下。
- 评论提交后立即显示，重新打开详情页仍存在。
- 删除确认取消时评论保留，确认后评论从列表和缓存中消失。
- 空评论不能提交。
- 评论按最新时间倒序排列。
- 现有首页轮播、新闻跳转、收藏、登录和 tabBar 功能保持可用。
